Instructions to compile and run Problem 1(c): Co-Occurrence Stripes matrix

1. We have provided a comprehensive `Makefile` in the root directory to heavily automate compilation and execution!
   Navigate to the root folder, and ensure Maven is compiled:
   make compile

2. To generate the stripes matrix, simply utilize the built-in Makefile tag. You can manually specify the required distance parameter 'd'. For example, if you want a co-occurrence window size of 4:
   make 1c d=4

   # BEHIND THE SCENES (Manual Hadoop Client Execution without Make):
   # rm -rf output_stripes
   # hadoop jar MapReduceWordCount/target/MapReduceWordCount-1.0-SNAPSHOT.jar com.nosql.assignment2.CoOccurrenceStripes Wikipedia-50-ARTICLES output_stripes output_final/part-r-00000 4
   #
   # ARGUMENT BREAKDOWN:
   # args[0]: Wikipedia-50-ARTICLES (Dataset)
   # args[1]: output_stripes (Output Path)
   # args[2]: output_final/part-r-00000 (Top 50 words dataset via DistributedCache context)
   # args[3]: 4 (Distance constraint 'd')

3. View the final Associative-Array MapWritable Metric Index (`Word -> {Word: Count, Word: Count}`):
   cat output_stripes/part-r-00000
